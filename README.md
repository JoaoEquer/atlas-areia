# atlas-areia

Plugins for [Atlas](https://github.com/marqueskaio/atlas), listed in the
[Atlas marketplace](https://github.com/marqueskaio/atlas-marketplace).

| Plugin | What it is |
|---|---|
| [`areia`](areia) | A warm, paper-like light theme: sand grounds, ink-dark text, state colors tuned to match. Data only, nothing runs. |

Each plugin sits in its own folder, named like the plugin, which is what Atlas requires. Its README
says what it does, what it reaches and how to install it.

## Checking a plugin

With Atlas installed:

```bash
atlas plugins validate areia
```
